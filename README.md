# GRC Templates

Study templates I built while learning **Governance, Risk & Compliance**. They are **generic examples** with fictional data, not documents from a real company.

| File | Purpose |
|---|---|
| [`risk-register.csv`](risk-register.csv) | Risk register (likelihood x impact scoring, ISO 27005 logic) |
| [`gdpr-processing-register.csv`](gdpr-processing-register.csv) | Record of processing activities (GDPR Art. 30) |
| [`iso27001-annexA-checklist.md`](iso27001-annexA-checklist.md) | Self-assessment checklist by control theme (ISO 27001:2022 Annex A) |
| [`password-policy.md`](password-policy.md) | Example password and access policy |

## Scoring used

`Risk score = Likelihood (1-4) x Impact (1-4)` : 1-4 low, 5-8 medium, 9-12 high, 13-16 critical.

## Sources

ANSSI (guides d'hygiène informatique, EBIOS RM), CNIL (RGPD), ISO/IEC 27001 and 27005 (concepts).
